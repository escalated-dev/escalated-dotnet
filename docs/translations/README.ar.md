<h1 align="center">Escalated for ASP.NET Core</h1>

<p align="center">
  أضف مكتب دعم متكاملًا إلى تطبيق ASP.NET Core الخاص بك.<br>
  تذاكر، واتفاقيات مستوى الخدمة (SLA)، وقواعد تصعيد، وصندوق وارد للوكلاء، وبوابة للعملاء، تُخزَّن عبر EF Core في قاعدة البيانات التي تختارها.

## البدء السريع

```bash
dotnet add package Escalated
dotnet ef database update --context EscalatedDbContext
```

سجّله في `Program.cs` باستخدام `builder.Services.AddEscalated(...)` و`app.MapEscalated()`، ثم افتح `/support`. يتطلب .NET 8+ وSQL Server أو SQLite أو PostgreSQL. يشرح [دليل البدء](../getting-started.md) الإعداد والتفويض، وتفعّل [واجهة Inertia](../inertia-ui.md) الشاشات المشتركة.
